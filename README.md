# RAWAN — Find Your Bag

A small, responsive brand landing page with a three-question interactive bag-personality quiz, result cards, and a founder-purpose story section.

## Preview locally

Open `index.html` in a browser. No build step or dependencies are required.

## Add the CEO and co-founder photo

The founder section is ready for the real photo. Add the approved image at `assets/founders.jpg` (create the `assets` folder first). The page will display it automatically; until then it shows a friendly photo placeholder. Replace the sample founder-story wording and quote in `index.html` with the founders’ own words before publishing.
